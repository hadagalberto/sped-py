## 6. Hostile-input sweep (milestone 5)

68 CLI invocations on malformed/edge inputs (empty, whitespace-only, 256-byte binary garbage, NUL bytes, broken framing, 2 MB fields, 5 MB lines, UTF-8 BOM, LF/mixed endings, framed signatures, unknown COD_VER, missing files, directories, paths with spaces and `çã o`, negative limits, 1 GB-scale line counts) produced **no tracebacks and no out-of-range exit codes** (`python tmp/audit_hostile.py`). Each defect found was fixed and covered in `tests/test_hardening.py`:

- UTF-8 sample-boundary detection → incremental decoder.
- Framed digital-signature markers → stripped.
- `compute_icms_totals` cross-block parent leakage → per-block parents.
- `get_dataframe` missing from public API → exported.
- CLI usage errors misclassified as I/O → `UsageError` → exit 2.
- Warning-only validation reported as failure → exit 0.
- `diff` aborting on malformed framing → line skipped.
- Missing pyarrow leaking `ImportError` → actionable extra error.
- Index silently accepting a missing source → fails closed.
- Repeated `obrig` tokens disabling required-field checks → normalized.
- Trailing CR stripping beyond the line terminator → single CR removed.
- Cross-reference checks limited to three registers → derived from layouts.

## 8. Resolved / accepted limitations

- **Old EFD layout gap-filling** is disclosed via `layout.gap_filled_fields` and the READMEs rather than silently asserted as version-exact. Re-extracting those four official PDFs with a version-specific parser remains future work; no invented field positions are present.
- **Validation/diff memory** is documented as an offline operation, not part of the constant-memory streaming core.
- **CST/CSOSN** tables are curated from the cited official publications with a documented manual verification procedure, not live-scraped.
